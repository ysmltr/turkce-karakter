Privacy Policy

Last updated: March 2025

This extension does not collect, store, or transmit any personal data. All processing happens locally in your browser.

1. Data Collection

The Turkish Character Converter extension does not collect any of the following:

  • Personal information (name, email, location, etc.)
  • Text you enter or convert
  • Browsing history or navigation data
  • Usage statistics or analytics data
  • Cookies or local storage data

2. Internet Connection

This extension works fully offline. Text conversion happens entirely in your browser's memory; no connection is made to any server, and no data is sent over the internet.

3. Third-Party Libraries

This extension uses the following open-source library as its conversion algorithm:

  • turkish-deasciifier — github.com/ustunozgur/turkish-deasciifier
    Developers: Ustun Ozgur & Mustafa Emre Acer
    Original algorithm: Dr. Deniz Yuret
    License: ISC (open source, free to use)

This library is bundled inside the extension and does not transmit any data externally.

4. Permissions

The extension only requests the minimum permissions needed to display its popup interface. It does not request access to your page content, personal data, or other tabs.

5. Children's Privacy

Since this extension does not collect data from any user, it is safe to use for all age groups, including children.

6. Changes

This privacy policy may be updated as needed. Significant changes will be announced on the Chrome Web Store page.

7. Contact

For questions regarding this privacy policy, please reach out via the Chrome Web Store support page.
